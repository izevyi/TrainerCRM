# Trainer CRM

## Описание

Trainer CRM — веб-приложение для персональных фитнес-тренеров.

Основная идея — заменить обычные заметки удобным календарем с расписанием клиентов, историей тренировок и отслеживанием прогресса.

---

## MVP (первая версия)

### Главный экран

- Календарь
- Список записей выбранного дня
- Кнопка "Добавить запись"

### Клиент

- ФИО
- Телефон
- Рост
- Вес
- Цель
- Заметки

### Тренировка

- Список упражнений
- Подходы
- Повторения
- Вес
- Комментарий

### История тренировок

- Просмотр всех тренировок клиента

### Замеры

- Вес
- Объемы тела
- Фото прогресса

---

## Будущие функции

- Повторить прошлую тренировку
- Поиск клиентов
- PDF-отчет
- Telegram-уведомления
